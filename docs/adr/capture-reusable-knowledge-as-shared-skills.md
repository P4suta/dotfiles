# Capture reusable knowledge as shared skills

## Context

Shared skills carry decision criteria across tasks and clients.
Research, implementation, debugging, reviews, failures, and feedback can supply reusable knowledge.

## Decision

Proactively apply knowledge-to-skills without waiting for a separate request.
Update an existing skill or focused reference before creating a skill for an uncovered workflow.
Keep applicability, supporting evidence, failure cases, and verification with the lesson.
Separate changing facts from durable instructions and require fresh checks when decisions depend on changing facts.
Preserve publication boundaries, confidential context, and the existing experimental maintenance setting.

## Alternatives

Conversation notes lack shared skill discovery.
A skill per observation fragments related guidance.

## Consequences

Routine tasks include small knowledge updates when evidence justifies reuse.
An observed fix does not establish an unrestricted rule.

## Confirmation

Validate skill structure, sources, prose, realistic behavior, and native discovery.
Install the shared source through the scoped workflow bundle on each affected host.
